# AI 图片编辑 PRD

> 状态：本轮讨论确认稿；产品流程已明确，模型后端接口待实现后对接。
> 本文只整理需求，不代表功能已经实现，也不作为开始开发、提交、推送或发布的授权。
> 不修改项目版本号，不打 tag，不发布版本。

## 1. 目标与核心边界

**在所有旧流程中的图片上增加「AI 编辑」模式，不新建一套图片管理流程。**

用户可以对已有图片填写修改要求，必要时涂抹要修改的区域，请求自己部署的模型生成编辑结果。例如：涂住人物手里的杯子，输入“把杯子换成一束花”，再对比结果并决定是否采用。

- 图片原有的上传、生成、添加、归属、保存和使用流程保持不变。
- 从电脑选择的图片，先通过现有流程添加，之后正常进入 AI 编辑；不增加独立的“从电脑选图直接编辑”流程。
- 不按角色、场景、道具、分镜等业务分类限制功能，所有旧流程中的图片均应可以进入编辑。
- 编辑结果只在用户明确采用后交回原入口，沿用现有保存和引用逻辑。
- 后端尚未实现；真实 URL、路径、字段和协议细节暂留待定，不阻塞产品交互讨论。

## 2. 本次范围

### 2.1 功能范围

1. AI 设置新增「图片编辑」服务类型。
2. 旧流程图片增加统一的 AI 编辑入口和编辑窗口。
3. 文字改图及自由涂抹遮罩局部重绘，按模型真实能力启用。
4. 编辑结果滑动对比。
5. 采用新图、继续编辑、返回调整。
6. 仅长期保留最终采用结果，清理本次编辑的临时数据。
7. 生成期间禁止关闭；有未采用修改时，关闭前确认放弃。

### 2.2 不增加的流程

- 不重新设计图片上传、素材库、项目归属或保存去向。
- 不要求用户先手工制作遮罩文件。
- 不建立多轮编辑结果的长期历史库。
- 不在采用结果时自动替换其他位置引用的图片。
- 不自动裁切模型结果并按遮罩拼回原图。

完整图层编辑器、自动分割选区、批量改图、模型训练部署等不属于本轮需求，不据此扩展实现范围。

## 3. AI 配置

### 3.1 新增服务类型

在「AI 设置 → 添加配置 → 服务类型」中新增 **「图片编辑」**，可附说明“支持局部重绘”。

该类型独立于现有图片生成和分镜图片生成，不改变旧流程使用的默认服务。编辑窗口只选择适用的编辑服务和模型。

配置界面优先复用已有的名称、服务地址、鉴权信息、模型名称、接口协议/路径和默认配置管理方式。具体必填字段按后端合同确定，不先写死未经确认的默认地址或鉴权形式。

### 3.2 两种编辑方式

| 用户操作 | 模式 | 请求的业务内容 |
| --- | --- | --- |
| 不涂抹，只输入要求 | 文字改图 | 原图 + 修改要求 |
| 涂抹区域并输入要求 | 遮罩局部重绘 | 原图 + 遮罩 + 修改要求 |

- 两种方式共用同一个编辑入口，并明确显示当前模式。
- 不涂抹仍须发送原图，不是从零生成图片。
- 文字改图模式按协议不传遮罩，不能以全白或全黑遮罩冒充无选区编辑。
- 全部擦除选区后按无选区处理，界面模式与实际请求保持一致。
- 模型仅支持遮罩重绘时，无选区应提示先涂抹。
- 模型不支持遮罩时，不得悄悄丢弃选区后按普通生成提交。
- 能力由接口和模型真实支持情况确定；是否需要配置项或能力标识，在对接阶段确定。勾选本身不能赋予模型能力。

原图、遮罩和修改要求属于每次编辑的输入，不是服务的固定配置。

### 3.3 接口待定边界

现在不要求用户提供后端 URL 或请求路径。待模型后端实现后，确认：

- 原图、遮罩、提示词等字段和鉴权方式。
- 文件、Base64 或 URL 传输方式，以及图片格式和尺寸限制。
- 遮罩的黑白含义、透明通道约定和尺寸要求。
- 同步返回或异步任务协议、结果结构及超时规则。

接口未就绪不阻塞界面需求讨论，但真实模型调用和端到端验收依赖接口完成。后续若做模拟演示，必须明确标注，不能宣称真实模型编辑成功。

## 4. 入口与操作流程

```text
旧流程中的已有图片
        ↓
     AI 编辑
        ↓
选择编辑服务/模型，输入修改要求
        ↓
按需涂抹选区，检查输入和模型能力
        ↓
      请求生成
        ↓
    滑动对比结果
        ↓
  ┌─────┼──────────┐
采用新图  继续编辑    返回调整
  ↓        ↓           ↓
交回原入口 以结果为原图  回到本轮输入图
结束编辑   开始下一轮    保留选区和描述重试
```

- 编辑使用用户实际打开并选择的图片，不能自动换成该对象的主图、最新图或其他版本。
- 各类图片共用编辑交互，不分别建立角色编辑器、分镜编辑器等。
- 采用结果时只更新本次目标，沿用来源入口现有的保存/引用管理方式，不改变同一文件的其他引用位置。
- 各入口如何接收最终结果属于技术适配，不新增“保存到哪里”的产品选择。

**界面建议：** 在现有图片预览中提供「AI 编辑」按钮；编辑窗口以较大区域展示图片，旁边放置模型选择、修改描述和生成按钮。具体布局在实施设计中完善，不构成新的业务流程。

## 5. 涂抹与遮罩

### 5.1 已确认的涂层行为

- 原图上叠加独立的半透明选区涂层，涂抹不修改原始图片。
- 用户能同时看清选区和原图轮廓；橡皮擦只移除选区，不擦除原图。
- 半透明程度只影响预览，不代表模型重绘强度。
- 选区先按选中/未选中表达，反复涂抹不应不断叠深或隐式改变编辑强度。
- 提交时发送干净原图和独立遮罩，不发送盖着彩色涂层的截图。

**界面建议：** 画笔、笔刷大小、橡皮擦、撤销、清空以及缩放/平移；选区可采用红色、约 40%～50% 不透明度。具体视觉参数和工具布局留给界面设计，不要求用户现在确定数值。

### 5.2 坐标与格式要求

- 遮罩与实际提交原图的尺寸、方向和坐标必须对应。
- 视图缩放、移动不能导致选区偏移；前端应把操作转换到正确的图像坐标。
- 若接口要求调整原图尺寸，遮罩必须同步处理。
- 白色表示编辑、黑色表示保留只是常见约定，具体输出按实际后端协议转换，不预设所有模型一致。

## 6. 生成与滑动对比

### 6.1 生成过程

- 提交前校验原图、修改要求、选区与模型能力；输入不满足要求时明确提示，不发送缺失原图或遮罩的替代请求。
- 同一请求处理中避免重复提交，防止重复生成和计费。
- 生成进行中不能关闭编辑窗口，关闭按钮、遮罩点击、Escape 等关闭途径均应遵守同一规则，并提示正在生成。
- 生成成功或失败后恢复关闭操作。请求须有超时处理，不能因请求永久等待而一直锁住窗口；具体时限在对接阶段确定。
- 应用被强制退出或网络中断不等于模型侧任务已取消。

### 6.2 滑动对比

- 返回结果后默认展示滑动对比：原图与编辑图对齐叠放，左侧原图、右侧编辑结果，分割线默认居中。
- 向右拖显示更多原图，向左拖显示更多结果；移动的是显示边界，不是图片本身。
- 标注「原图」「编辑后」，对比时默认隐藏选区涂层。
- 缩放和平移查看细节时，两张图同步变化。
- 尺寸不同但宽高比相同，按相同显示尺寸对齐；仅调整预览，不修改保存的结果文件。
- 宽高比不同时，提示差异并使用并排预览，不能通过拉伸或静默裁剪冒充准确对比。

### 6.3 遮罩外的变化

用户已明确选择通过滑动对比自行判断：

- 直接使用模型返回的整张图，不按遮罩裁切、拼回原图。
- 不承诺遮罩外逐像素不变，也不因为选区外有变化就自动拒绝结果。
- 是否满意由用户决定；图片格式、保存等技术校验仍需执行。

## 7. 结果操作与连续编辑

| 操作 | 行为 | 项目当前图片 |
| --- | --- | --- |
| 采用新图 | 保存最终结果，交回原入口，结束编辑 | 采用成功后更新 |
| 继续编辑 | 以本轮结果为下一轮原图，清空旧选区和修改描述 | 不变 |
| 返回调整 | 回到本轮输入图，保留本轮选区和描述重新尝试 | 不变 |

例子：项目原图为 A，第一轮把杯子改成花得到 B，再以 B 修改衣服得到 C。

- 第二轮滑动对比的是 B 与 C。
- 第二轮「返回调整」回到 B，保留第二轮选区和描述，不回到 A。
- 全部编辑期间项目仍引用 A，最终采用 C 才更新为 C。
- 不提供多轮历史库或跨会话的历史回退。

## 8. 保存、清理与关闭

### 8.1 只保留最终采用结果

- 编辑结果以独立文件处理，不直接覆盖原图文件。
- 中间及未采用结果只是本次编辑的临时数据，不进入长期素材或图片历史。
- 编辑期间保留当前对比、继续编辑及返回调整所需文件，不能提前清理正在使用的输入。
- 最终结果持久保存和原入口保存/引用更新均成功后，才提示采用成功。
- 采用失败保持原引用，并保留结果供重试；不能先清理再发现保存失败。
- 本次编辑结束后清理未采用结果和临时遮罩；项目原有图片、已采用结果及其他素材不自动删除。
- “只保留最终结果”指本次新增的编辑结果，不是删除或重写原有图片历史。

### 8.2 关闭确认

非生成状态下，存在未采用的修改内容或结果时，关闭前提示：

> 放弃本次编辑？未采用的结果将不再保留。
>
> 「继续编辑」　「放弃并关闭」

- 「继续编辑」：保留当前原图、选区、描述和预览结果，窗口不关闭。
- 「放弃并关闭」：关闭窗口，项目当前图片不变，清理本次未采用临时数据。
- 生成状态优先遵守禁止关闭规则，不能通过放弃确认绕过。

## 9. 异常与基本约束

| 情形 | 应有行为 |
| --- | --- |
| 未配置编辑服务 | 提示先配置，不自动拿原来的文生图服务代替 |
| 原图无法读取或格式不支持 | 阻止请求并说明原因，不退化为无图生成 |
| 修改要求为空 | 提示填写要求，不发送生成请求 |
| 鉴权、网络、模型或超时错误 | 显示失败，保留当前图片及本轮选区、描述以便重试，恢复关闭操作 |
| 返回图片无效或无法保存 | 不更新图片引用，不提示已保存或采用成功 |
| 生成期间来源被删除或当前图片发生变更 | 不能把旧结果静默覆盖到新的目标；具体冲突提示由实施设计确定 |
| 临时文件清理 | 只清理本次编辑拥有且不再使用的临时数据，不误删其他素材 |

数据处理延续 SQLite 保存记录/路径、本地保存媒体文件的方式。具体表结构、临时目录和清理方式属于技术设计，不在本 PRD 预设。

原图和遮罩会发送到用户配置的模型服务，不宣称图片绝不离开电脑；不擅自新增第三方图床中转，不在日志或错误提示中暴露 API Key。格式、尺寸、大小等限制按实际接口确定，不编造数值。

## 10. 验收场景

> 以下描述应达到的行为，不表示已实现或已测试通过。真实模型编辑验收需等待后端接口就绪。

| 场景 | 操作 | 可判断的结果 |
| --- | --- | --- |
| 配置编辑服务 | 添加「图片编辑」配置 | 编辑入口可选，旧生成服务配置不受影响 |
| 全部旧图片流程 | 分别从现有生成、上传、素材等图片入口进入 | 使用同一编辑能力，不按业务类型或来源排除 |
| 先添加再编辑 | 按旧流程添加电脑图片，再编辑并采用 | 沿用原入口保存，无新增上传或保存去向流程 |
| 正确图片与目标 | 选择特定图片编辑并采用 | 请求使用所选图片；只更新本次目标，不影响其他引用位置 |
| 文字改图 | 模型支持无遮罩编辑，不涂抹并输入要求 | 发送原图和要求，不发送空白遮罩冒充局部重绘 |
| 遮罩重绘 | 涂住杯子，输入替换要求 | 发送干净原图、独立遮罩和要求，不发送红色预览截图 |
| 能力不匹配 | 仅支持遮罩的模型无选区，或不支持遮罩的模型有选区 | 明确提示，不忽略输入继续提交 |
| 选区坐标 | 缩放、平移后涂抹，再恢复视图 | 选区始终对应同一物体；实际遮罩与提交原图对齐 |
| 清空选区 | 擦除全部选区 | 按无选区处理，显示模式和请求一致 |
| 滑动对比 | 拖动分割线并放大细节 | 显露范围变化，两图不相对移动，选区涂层隐藏 |
| 宽高比不同 | 模型返回不同宽高比结果 | 提示并改用并排预览，不拉伸或裁剪伪造对齐 |
| 遮罩外变化 | 模型修改了选区外区域 | 展示完整结果，交给用户判断，不额外拼图 |
| 多轮编辑 | A → B → C | 第二轮比较 B/C；返回调整恢复 B 及第二轮输入；项目仍引用 A |
| 最终采用 | 采用 C | C 保存并交回原入口成功后更新；B 等临时数据被清理，原有 A 不自动删除 |
| 采用失败 | 本地保存或原入口更新失败 | 原引用不变、结果保留供重试，不虚报成功 |
| 关闭确认 | 有未采用内容，分别选择继续编辑或放弃关闭 | 前者保留现场，后者清理临时结果但不改变项目当前图片 |
| 生成期间关闭 | 请求进行中尝试关闭 | 不能关闭；成功、失败或超时后恢复关闭操作 |

模型是否完全遵从修改描述由实际效果判断，不能承诺每次生成都完美；软件保证输入传递、选区对齐、预览、保存及失败处理正确。
